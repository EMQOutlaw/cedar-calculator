# CEDAR Calculator

A compact standalone Quickshell calculator, extracted from CEDAR Shell.

## Branch policy

- `dev` is the default branch and the destination for all new code and updates.
- `main` is the stable release branch. Promote reviewed work from `dev` only with explicit owner approval.
- The initial `main` branch reserves the stable channel; application development is published on `dev` after testing and review.

The calculator is being separated from the shell. This bootstrap commit does not contain the application yet.
